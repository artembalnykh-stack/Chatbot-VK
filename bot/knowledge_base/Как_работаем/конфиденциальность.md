# Конфиденциальность и NDA

По запросу подписываем NDA до начала работы. Это стандартная практика для проектов, где клиент передаёт внутренние материалы, доступы или данные клиентов.

Как обращаемся с данными:

- доступ к проекту получают только специалисты, занятые в задаче;
- конфиденциальные данные не передаём в публичные ИИ-модели без анонимизации;
- после завершения проекта доступы, которые больше не нужны, удаляем.

Мы не запрашиваем персональные данные клиентов без необходимости. Если для работы нужны доступы к CRM или рекламным кабинетам, оформляем их через отдельного пользователя с ограниченными правами.

Платежи проходят через платёжные сервисы и банк. Данные банковских карт студия не хранит.
