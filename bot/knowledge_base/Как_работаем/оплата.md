# Оплата услуг

Работаем по предоплате 50% перед стартом и 50% после утверждения результата.

Способы оплаты:

- перевод для физических лиц;
- счёт для юридических лиц и ИП;
- оплата по ссылке.

Для физлиц и самозанятых предоставляем чек, для компаний — закрывающие документы. Все суммы фиксируем до начала работ, скрытых доплат нет.

Если задача меняется по ходу проекта, составляем дополнительную смету и согласуем её отдельно. Без согласования объём не увеличиваем.

Оплата принимается в рублях. Домен, хостинг, подписки на сервисы и реклама оплачиваются клиентом отдельно, если они нужны для проекта.
