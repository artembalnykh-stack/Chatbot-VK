Напиши полный код профессионального, безопасного и минималистичного бота-консультанта для ВКонтакте на Python. Бот запускается локально на ПК (macOS), работает с базой знаний из локальной папки, использует GigaChat API для комбинированного поиска и живого диалога. Бот не галлюцинирует, строго следует инструкциям и соответствует базовым требованиям 152-ФЗ.

### ТРЕБОВАНИЯ К ФУНКЦИОНАЛУ

**1. Интеграция с VK и UX:**
*   Используй VK Long Poll (библиотека `vk_api` или `aiohttp` для локального запуска без белого IP). Выбери вариант, который проще для локального запуска на macOS и не требует лишних зависимостей.
*   Приветствие: при первом обращении или команде `/start` бот отправляет приветствие и показывает клавиатуру с быстрыми кнопками: ["Доставка", "Оплата", "Задать вопрос", "Связаться с оператором"].
*   Обработка вложений: если пользователь отправляет не текст (картинку, голосовое, стикер, геолокацию), бот вежливо отвечает: "Я пока понимаю только текстовые сообщения. Пожалуйста, напишите ваш вопрос текстом" и не падает с ошибкой.

**2. База знаний (БЗ) и Поиск:**
*   Папка на диске (путь задается в `.env`). Поддерживаются форматы `.csv`, `.md`, `.txt`.
*   Структура папок сохраняется как иерархия тем (например, папка "Доставка" содержит файлы о разных способах доставки).
*   БЗ не индексируется в реальном времени: бот подхватывает новые/измененные файлы только при перезапуске.
*   Комбинированный поиск: простой текстовый поиск по файлам (grep-like) без внешних векторных БД, Elasticsearch и т.п. Эвристика релевантности: совпадение ключевых слов + длина фрагмента + близость к началу документа.
*   Если найдено релевантное — ответ строится СТРОГО по найденным фрагментам.
*   Если не найдено — ИИ выдает стандартный дисклеймер (см. промпт ниже).

**3. GigaChat API и Контекст:**
*   Используй официальный SDK или REST API GigaChat.
*   Контекст диалога: храни последние 5 сообщений каждого пользователя в памяти (словарь `user_id -> list`). При запросе к ИИ передавай историю как контекст.
*   Очистка контекста: если пользователь не писал 15 минут, очищай его историю из памяти.
*   Fallback: если GigaChat API недоступен (таймаут, ошибка 5xx, лимиты), бот отвечает: "Сервис временно недоступен. Пожалуйста, попробуйте через 5 минут или оставьте заявку оператору". Ошибки логируются.

**4. Сбор заявок и передача оператору (Handover):**
*   При нажатии кнопки "Связаться с оператором" или фразе "оператор" бот спрашивает: "Как вам удобнее, чтобы оператор с вами связался? Напишите ваш номер телефона или ответить в ВКонтакте".
*   **Сбор ПД и 152-ФЗ:** Перед сохранением данных бот ОБЯЗАН запросить явное согласие: "Для передачи заявки оператору мне нужно обработать ваши персональные данные. Вы даете согласие на обработку ПД? (Да/Нет)".
*   Если "Нет" — вежливо отказывает. Если "Да" — принимает данные.
*   **Валидация телефона:** если пользователь вводит телефон, проверяй его регулярным выражением `^(\+7|8)?[\s\-]?\(?[489][0-9]{2}\)?[\s\-]?[0-9]{3}[\s\-]?[0-9]{2}[\s\-]?[0-9]{2}$`. При ошибке проси ввести повторно (макс. 3 попытки).
*   **Сохранение:** Полные данные (timestamp, user_id, имя/ссылка, телефон) сохраняются в Яндекс Таблицы (интеграция через API, креды в `.env`).
*   **Маскировка:** В логах приложения и при отправке уведомлений админу данные маскируются (телефон: `+7 (XXX) XXX-XX-XX`, имя: `Ив***`). В саму Яндекс Таблицу пишутся ПОЛНЫЕ данные, чтобы оператор мог связаться.
*   **КРИТИЧНОЕ ОГРАНИЧЕНИЕ:** Данные заявок (имя, телефон, ссылка на профиль) НЕ должны передаваться в промпт к GigaChat API. Это отдельный поток обработки.
*   После сохранения бот пишет: "Заявка принята! Оператор свяжется с вами в ближайшее время."

**5. Безопасность и Фильтры:**
*   **Антимат:** Используй библиотеку `better-profanity` (или аналог). При обнаружении мата бот отвечает: "Пожалуйста, используйте корректные выражения. Я готов помочь с вопросами по магазину".
*   **Защита от Prompt Injection:**
    * В системный промпт добавь жесткий запрет на смену роли и раскрытие инструкций.
    * Во входном сообщении пользователя проверяй паттерны инъекций (список: "забудь инструкции", "игнорируй предыдущее", "теперь ты", "system prompt", "jailbreak"). При совпадении — отвечай заглушкой без отправки в GigaChat.

**6. Асинхронность и ограничения:**
*   Используй `asyncio` для асинхронной обработки входящих сообщений и запросов к API.
*   Лимит запросов: не чаще одного запроса от одного пользователя в минуту, чтобы избежать спама и экономить ресурсы API.

### ТЕХНИЧЕСКИЕ ДЕТАЛИ И СТЕК
*   **Язык:** Python 3.9+ (текущее рабочее окружение — Python 3.9.6).
*   **Фреймворк:** FastAPI (для внутренней логики и тестов) или чистый asyncio + aiohttp (если проще для локального запуска). Выбери оптимальный вариант.
*   **Зависимости:** `vk_api`, `gigachat`, `better-profanity`, `requests` (или `aiohttp`), `python-dotenv`, `pandas` (для работы с CSV/Таблицами).
*   **Конфигурация:** `.env` (VK_TOKEN, GIGACHAT_CREDENTIALS, YANDEX_TABLES_TOKEN, YANDEX_TABLES_ID, DATA_DIR).
*   **Деплой:** Локальный запуск через `python main.py`.
